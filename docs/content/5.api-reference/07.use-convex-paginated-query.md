---
title: useConvexPaginatedQuery
description: Reference for the paginated query composable.
---

`useConvexPaginatedQuery` subscribes to a paginated Convex query and accumulates its pages. It follows `usePaginatedQuery` from `convex/react`: each instance gets its own pagination id, and pages the server asks to split are split.

## Import

```ts [Nuxt]
const { data, loadMore } = await useConvexPaginatedQuery(api.tasks.paginated, {}, { numItems: 20 })
```

```ts [Vue]
import { useConvexPaginatedQuery } from 'vue-convex'
```

## Signature

```ts
function useConvexPaginatedQuery<Query extends PaginatedQueryReference>(
  query: MaybeRefOrGetter<Query>,
  args: MaybeRefOrGetter<Omit<FunctionArgs<Query>, 'paginationOpts'> | 'skip'>,
  options: {
    numItems: number
    server?: boolean
    auth?: 'required' | 'optional' | 'none'
  },
): UseConvexPaginatedQueryReturn<Item> & PromiseLike<UseConvexPaginatedQueryReturn<Item>>

interface UseConvexPaginatedQueryReturn<Item> {
  data: Readonly<Ref<Item[]>>
  error: Readonly<Ref<Error | ConvexError<Value> | null>>
  status: Readonly<Ref<'idle' | 'pending' | 'success' | 'error'>>
  isPending: ComputedRef<boolean>
  isSkipped: ComputedRef<boolean>
  isDone: Readonly<Ref<boolean>>
  isLoadingMore: Readonly<Ref<boolean>>
  loadMore: (numItems?: number) => boolean
  reset: () => void
  suspense: () => Promise<Item[]>
}
```

## Parameters

| Parameter | Type | Meaning |
| --- | --- | --- |
| `query` | `FunctionReference<'query'>` | Generated paginated query reference |
| `args` | `Omit<FunctionArgs<Query>, 'paginationOpts'> \| 'skip'` | Query args without `paginationOpts`, or `"skip"` |
| `options.numItems` | `number` | Size of the first page, and the default for `loadMore()` |
| `options.server` | `boolean` | Fetch the first page during SSR when awaited |
| `options.auth` | `'required' \| 'optional' \| 'none'` | Same as [useConvexQuery](/api-reference/use-convex-query) |

## Return value

| Field | Meaning |
| --- | --- |
| `data` | Items from all loaded pages |
| `status` | `success` once the first page is loaded |
| `isDone` | `true` when there are no more pages |
| `isLoadingMore` | `true` while a later page is loading |
| `loadMore` | Requests the next page. Returns `false` while a page is loading, when done, or when skipped |
| `reset` | Drops loaded pages and restarts from the first page |

## Behavior

- Awaiting on the server fetches the first page over HTTP and hydrates it; the client then subscribes to that page over the WebSocket
- Restarts from the first page when reactive args change, or when the server reports an `InvalidCursor`
- Clears all pages when `args` becomes `"skip"`
