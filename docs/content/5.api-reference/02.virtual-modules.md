---
title: Virtual Modules
description: Reference for the Nuxt-only aliases created by nuxt-convex.
---

`nuxt-convex` creates aliases so app code imports the public runtime without reaching into generated or build directories.

## Always available

| Import | Where | What it exposes |
| --- | --- | --- |
| `#convex` | app | The root composables, `isConvexError`, the auth components and the pagination helpers |
| `#convex/advanced` | app | The controller and the raw client helpers |
| `#convex/api` | app and server | The generated Convex `api`, `internal` and `components` exports |
| `#convex/server` | server only | The Nitro helpers: `useConvexServer`, `serverConvexQuery`, `serverConvexMutation`, `serverConvexAction`, `getConvexToken`, `requireConvexAuth`, `toConvexH3Error`, and their types |

## Available when `storage: true`

| Import | What it exposes |
| --- | --- |
| `#convex/storage` | The storage helpers from `vue-convex/storage` |

## Available when `r2: true`

There is no R2-specific virtual module. Enabling `r2: true` only adds the `useConvexR2Upload` auto-import.

## Examples

```vue [app/pages/tasks.vue]
<script setup lang="ts">
import { api } from '#convex/api'

const { data } = await useConvexQuery(api.tasks.list)
</script>
```

```ts [app/utils/errors.ts]
import { isConvexError } from '#convex'

export const isNotFound = (error: unknown) => isConvexError(error, 'NOT_FOUND')
```

```ts [server/api/stats.get.ts]
import { api } from '#convex/api'
import { serverConvexQuery } from '#convex/server'

export default defineEventHandler(event => serverConvexQuery(event, api.tasks.stats))
```
