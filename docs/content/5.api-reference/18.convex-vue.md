`convexVue` is the Vue plugin that creates the Convex runtime every composable reads from. `nuxt-convex` installs it for you from your module options, so in Nuxt you never call it.

## Import

```ts [Vue]
import { convexVue } from 'vue-convex'
```

## Usage

```ts [src/main.ts]
import { createApp } from 'vue'
import { convexVue } from 'vue-convex'
import App from './App.vue'

createApp(App)
  .use(convexVue, { url: import.meta.env.VITE_CONVEX_URL })
  .mount('#app')
```

## Options

```ts
interface ConvexVueOptions {
  url?: string
  clientOptions?: ConvexClientOptions
  server?: boolean
  hydration?: ConvexHydrationAdapter
  serverAuth?: ConvexServerAuth
  initialAuth?: { isAuthenticated: boolean }
}
```

| Option | Default | Meaning |
| --- | --- | --- |
| `url` | | Convex deployment URL. Without it the runtime starts disconnected; connect later with the [controller](/api-reference/use-convex-controller). |
| `clientOptions` | | Passed to the browser `ConvexClient` (`convex/browser`). `logger` and `skipConvexDeploymentUrlCheck` also reach the HTTP client. |
| `server` | `true` | Run awaited queries during SSR. Each query can override it with its `server` option. |
| `hydration` | | Hands SSR results to the client. Without it the client starts empty and loads every query over the WebSocket. |
| `serverAuth` | | Server only: `{ getToken }` returns the request's JWT. It's called at most once per app instance and never serialized. |
| `initialAuth` | | Auth state known before the client connects, usually from SSR, so the auth components render and hydrate without flipping. |

## Hydration adapter

```ts
interface ConvexHydrationAdapter {
  /** Server: record a settled query */
  set: (key: string, entry: ConvexHydrationEntry) => void
  /** Client: read a settled query. Only called while isHydrating() is true */
  get: (key: string) => ConvexHydrationEntry | undefined
  isHydrating: () => boolean
}

type ConvexHydrationEntry
  = | { v: JSONValue }
    | { e: { message: string, data?: JSONValue } }
```

Entries are plain JSON: values go through `convexToJson`, so `bigint` and `ArrayBuffer` survive, and a `ConvexError` keeps its `data`. Serialize them into your HTML on the server, read them back on the client, and return `false` from `isHydrating()` once the app has mounted. In Nuxt, the module stores them in the payload. See [Server Rendering](/vue-guide/server-rendering) for a plain Vue setup.
