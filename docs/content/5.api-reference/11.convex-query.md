title: ConvexQuery

`ConvexQuery` is a Nuxt-only global component that renders query states through slots.

## Example

```vue [app/pages/tasks.vue]
<script setup lang="ts">
import { api } from '#convex/api'
</script>

<template>
  <ConvexQuery :query="api.tasks.list" :args="{ userId: 'user_123' }">
    <template #loading>
      Loading tasks...
    </template>

    <template #error="{ error }">
      {{ error.message }}
    </template>

    <template #empty>
      No tasks yet.
    </template>

    <template #default="{ data }">
      <ul>
        <li v-for="task in data" :key="task._id">
          {{ task.title }}
        </li>
      </ul>
    </template>
  </ConvexQuery>
</template>
```

## Props

| Prop | Type | Meaning |
| --- | --- | --- |
| `query` | `FunctionReference<'query'>` | Query reference |
| `args` | `FunctionArgs<Query> \| 'skip'` | Query arguments, reactive |
| `options` | `UseConvexQueryOptions` | Same options accepted by `useConvexQuery`, read once |
| `suspense` | `boolean` | Waits for the first result before rendering on the client too |

## Slots

- `loading`
- `error`
- `empty`
- `default`

## Behavior

- Uses `useConvexQuery` internally
- On the server, waits for the first result (unless `options.server` is `false`) and hydrates it, so the client renders the same slot without a loading flash
- A failing query renders the `error` slot on the server and the client; it never fails the request
- Treats `undefined`, `null` and an empty array as empty states, and a skipped query as empty
