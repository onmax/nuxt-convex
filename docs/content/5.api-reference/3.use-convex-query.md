title: useConvexQuery
description: Reference for the primary read composable shared by nuxt-convex and vue-convex.
---

`useConvexQuery` subscribes to one Convex query and keeps the result updated.

## Import

```ts [Nuxt]
const { data } = await useConvexQuery(api.tasks.list, { userId: 'demo' })
```

```ts [Vue]
import { useConvexQuery } from 'vue-convex'
```

## Signature

```ts
function useConvexQuery<Query extends FunctionReference<'query'>>(
  query: MaybeRefOrGetter<Query>,
  args: MaybeRefOrGetter<FunctionArgs<Query> | 'skip'>,
  options?: {
    server?: boolean
    keepPreviousData?: boolean
    auth?: 'required' | 'optional' | 'none'
  },
): UseConvexQueryReturn<Query> & PromiseLike<UseConvexQueryReturn<Query>>

interface UseConvexQueryReturn<Query> {
  data: Readonly<Ref<FunctionReturnType<Query> | undefined>>
  error: Readonly<Ref<Error | ConvexError<Value> | null>>
  status: Readonly<Ref<'idle' | 'pending' | 'success' | 'error'>>
  isPending: ComputedRef<boolean>
  isSkipped: ComputedRef<boolean>
  suspense: () => Promise<FunctionReturnType<Query> | undefined>
}
```

## Parameters

| Parameter | Type | Meaning |
| --- | --- | --- |
| `query` | `FunctionReference<'query'>` | Generated Convex query reference, or a getter returning one |
| `args` | `FunctionArgs<Query> \| 'skip'` | Query arguments or `"skip"` to disable the subscription |
| `options.server` | `boolean` | Fetch during SSR when awaited. Defaults to the plugin's `server` option |
| `options.keepPreviousData` | `boolean` | Keep the previous result while the query for new args loads |
| `options.auth` | `'required' \| 'optional' \| 'none'` | `required` stays idle until authenticated. `none` runs SSR without fetching a token. Defaults to `optional` |

## Return value

| Field | Type | Meaning |
| --- | --- | --- |
| `data` | `Ref<T \| undefined>` | Latest query result |
| `error` | `Ref<Error \| null>` | Latest query error. Use `isConvexError(error, code?)` to read `ConvexError` data |
| `status` | `Ref<'idle' \| 'pending' \| 'success' \| 'error'>` | `idle` when skipped |
| `isPending` | `ComputedRef<boolean>` | `status === 'pending'` |
| `isSkipped` | `ComputedRef<boolean>` | `status === 'idle'` |
| `suspense` | `() => Promise<T \| undefined>` | Resolves with the first result and rejects on error |

## Behavior

- The return value is awaitable. `await useConvexQuery(...)` resolves with the same refs once the first result or error is in, and never rejects.
- On the server, awaiting fetches the query once per request over HTTP (authenticated when the plugin has `serverAuth`) and records it for hydration. Without `await`, nothing is fetched and the query renders as pending.
- On the client, a hydrated result is shown immediately, then the WebSocket subscription takes over. The client never fetches over HTTP.
- Changing args resets `data` unless `keepPreviousData` is set. Deep-equal args don't resubscribe.
