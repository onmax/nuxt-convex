---
title: useConvexHttpClient
description: Reference for the advanced helper that returns the active HTTP client.
---

`useConvexHttpClient` returns the current `ConvexHttpClient` instance.

## Import

```ts
import { useConvexHttpClient } from 'vue-convex/advanced'
```

In Nuxt, the same helper is available from `#convex/advanced`.

## Signature

```ts
function useConvexHttpClient(): ConvexHttpClient
```

## Behavior

- Throws when the runtime has no URL
- The client is unauthenticated, and created on first use
- In Nuxt server routes, use [`useConvexServer`](/nuxt-module/server-routes) instead: it authenticates as the request's user
