Use this guide when you are wiring `vue-convex` directly into a standalone Vue 3 app.

## Before you begin

Make sure you already have:

- a Vue 3 app
- a `convex/` directory in the same project
- a Convex deployment URL exposed as `VITE_CONVEX_URL`

## Install the packages

```bash [Terminal]
pnpm add vue-convex convex
```

## Register the plugin

```ts [src/main.ts]
import { createApp } from 'vue'
import { convexVue } from 'vue-convex'
import App from './App.vue'

createApp(App)
  .use(convexVue, { url: import.meta.env.VITE_CONVEX_URL })
  .mount('#app')
```

If you omit `url`, the plugin starts disconnected and you need the [controller](/vue-guide/controller) to connect later.

## Generate the typed API

Run Convex once before you import generated types from the frontend.

```bash [Terminal]
npx convex dev
```

That command creates a development deployment, writes `VITE_CONVEX_URL` to `.env.local` (when your `package.json` lists `vite`), and generates `convex/_generated/`. Vite loads `.env.local` by itself. Keep it running while you work: it pushes every change to your functions.

## Verify the result

```vue [src/components/TaskList.vue]
<script setup lang="ts">
import { useConvexQuery } from 'vue-convex'
import { api } from '../../convex/_generated/api'

const { data: tasks, status } = useConvexQuery(api.tasks.list)
</script>

<template>
  <p v-if="status === 'pending'">
    Loading…
  </p>
  <ul v-else>
    <li v-for="task in tasks" :key="task._id">
      {{ task.title }}
    </li>
  </ul>
</template>
```

The setup is working when the generated import resolves and the query returns data.
