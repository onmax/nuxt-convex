---
title: Pagination
description: Build client-side paginated feeds with useConvexPaginatedQuery and Convex paginated query functions.
---

Use `useConvexPaginatedQuery` for a feed that loads one page at a time. Every loaded page stays subscribed, so edits to any item show up live.

## Write the Convex query

Your Convex query must accept `paginationOpts` and return a `PaginationResult`.

```ts [convex/tasks.ts]
import { paginationOptsValidator } from 'convex/server'
import { v } from 'convex/values'
import { query } from './_generated/server'

export const paginated = query({
  args: {
    status: v.optional(v.string()),
    paginationOpts: paginationOptsValidator,
  },
  handler: async (ctx, { status, paginationOpts }) => {
    let q = ctx.db.query('tasks').order('desc')
    if (status)
      q = q.filter(doc => doc.eq(doc.field('status'), status))
    return await q.paginate(paginationOpts)
  },
})
```

You do not pass `paginationOpts` from the component. `useConvexPaginatedQuery` injects it for you.

## Subscribe from the client

```vue [src/components/TaskFeed.vue]
<script setup lang="ts">
import { useConvexPaginatedQuery } from 'vue-convex'
import { api } from '../../convex/_generated/api'

const { data, isPending, isDone, isLoadingMore, loadMore } = useConvexPaginatedQuery(
  api.tasks.paginated,
  {},
  { numItems: 20 },
)
</script>
```

## Reset on filter changes

Reactive arguments automatically clear the current pages and restart from the first page.

```vue [src/components/FilteredFeed.vue]
<script setup lang="ts">
import { useConvexPaginatedQuery } from 'vue-convex'
import { api } from '../../convex/_generated/api'

const status = ref('active')

const { data, loadMore, isDone } = useConvexPaginatedQuery(
  api.tasks.paginated,
  computed(() => ({ status: status.value })),
  { numItems: 20 },
)
</script>
```

## Skip pagination until the inputs exist

```ts
const { data, isSkipped } = useConvexPaginatedQuery(
  api.tasks.byProject,
  () => projectId.value ? { projectId: projectId.value } : 'skip',
  { numItems: 20 },
)
```

For queries that need a signed-in user, `{ numItems: 20, auth: 'required' }` does the same without the getter.

## Use the optimistic helpers when needed

`vue-convex` exports `insertAtTop`, `insertAtBottomIfLoaded`, `insertAtPosition` and `optimisticallyUpdateValueInPaginatedQuery`, the same helpers as `convex/react`, for optimistic updates on paginated queries:

```ts
import { insertAtTop, useConvexMutation } from 'vue-convex'

const { mutate: addTask } = useConvexMutation(api.tasks.add, {
  optimisticUpdate: (localStore, args) => insertAtTop({
    paginatedQuery: api.tasks.paginated,
    argsToMatch: {},
    localQueryStore: localStore,
    // A placeholder document; the server result replaces it when the mutation lands
    item: placeholderTask(args),
  }),
})
```

## Verify the result

The setup is working when:

- the first page loads into `data`
- `loadMore()` appends another page
- changing the arguments resets the feed

## Render the first page on the server

Like `useConvexQuery`, the composable is awaitable. With server rendering (Nuxt, or your own [SSR setup](/vue-guide/server-rendering)), awaiting it fetches the first page on the server and hydrates it; `loadMore()` then continues in the browser.

```ts
const { data, loadMore } = await useConvexPaginatedQuery(api.tasks.paginated, {}, { numItems: 20 })
```

Pass `server: false` in the options to keep it client-only.
