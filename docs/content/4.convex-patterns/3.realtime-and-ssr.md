---
title: Realtime and SSR
description: How queries render on the server, hydrate on the client, and then stay live over the WebSocket.
---

Queries render on the server only when you await them. The result goes to the client in the payload, and the client then subscribes over the WebSocket.

## How it works

```ts
const { data, error, status } = await useConvexQuery(api.tasks.list, { userId: 'demo' })
```

1. On the server, `await` runs the query once over `ConvexHttpClient`. Identical queries in the same request share one fetch.
2. The result, or the error, is stored in the payload under a `$convex:` key. Values are encoded with `convexToJson`, so `bigint` and `ArrayBuffer` survive, and `ConvexError` data is kept.
3. While the client hydrates, it reads that entry, so the first render matches the server HTML. It doesn't fetch over HTTP again.
4. The client subscribes over the WebSocket and replaces the value as updates arrive.

Awaiting never rejects: check `error` or `status`. `<ConvexQuery>` and `<ConvexPaginatedQuery>` await for you on the server and render their `error` slot when a query fails.

Paginated queries work the same way for their first page: `await useConvexPaginatedQuery(...)` fetches it on the server, and the client continues from there.

## Authenticated SSR

When the request has a session, nuxt-convex resolves its Convex token on the server and uses it for SSR queries. Only `isAuthenticated` reaches the client (in `useState('convex:auth')`), never the token, so `<ConvexAuthenticated>` and friends render on the server and hydrate without flipping.

Per query, `auth` tunes this:

- `auth: 'required'` keeps the query idle until the user is authenticated, so you don't need `computed(() => isAuthenticated.value ? args : 'skip')`.
- `auth: 'none'` marks a query whose result doesn't depend on the user. SSR runs it without resolving a token.

## When to disable SSR

Use `{ server: false }` or set `convex.server = false` when:

- the page is private and SEO does not matter
- you want to avoid server-side Convex requests entirely
